Minecraft modder & web developer. Suka ngoprek Forge 1.20.1, bikin minigame kustom, dan eksperimen web.

- 🎵 **[spoticraft-player](https://github.com/hamdan-sgpt/spoticraft-player)** — Web player audio untuk plugin SpotiCraft Minecraft ([Live Demo](https://hamdan-sgpt.github.io/spoticraft-player/)).
- 🚪 **[exit8-minecraft-plugin](https://github.com/hamdan-sgpt/exit8-minecraft-plugin)** — Plugin Paper/Spigot adaptasi game horor lorong stasiun The Exit 8 (8番出口).
- 🪪 **[RPGIdentityCard](https://github.com/hamdan-sgpt/RPGIdentityCard)** — Plugin KTP Indonesia yang di-render langsung ke custom map in-game.
- 🩸 **[dead-by-daylight-mod](https://github.com/hamdan-sgpt/dead-by-daylight-mod)** — Adaptasi gameplay horror asimetris Dead by Daylight di Minecraft.
