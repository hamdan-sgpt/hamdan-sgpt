### 👨‍💻 About Me

```yaml
name: Hamdan
alias: hamdan-sgpt
role: Game Developer & Systems Engineer
core_engine: Java (Minecraft Forge & Paper/Spigot)
current_focus:
  - High-intensity multiplayer minigames with custom GUIs
  - Proximity voice chat integration & game state synchronization
  - Procedural arena building & real-time packet networking
hobbies: [Modding, Assetto Corsa CSP Light Editing, Sound Design, Web Dev]
```

- 🎮 **Specialized in Minecraft 1.20.1 Forge & Paper/Spigot Modding**: Building production-grade multiplayer mods with network packet handling, custom screens/widgets, custom entity/block models, and voice chat plugins.
- ⚡ **Gameplay & Minigame Mechanics**: Created adaptations of psychological survival games like **Going Seventeen: Don't Lie**, **The Exit 8**, and **Dead by Daylight**.
- 🛠️ **Full Workflow Engineering**: From procedural texture generation and custom soundscapes to automated multi-client local testing launchers.
