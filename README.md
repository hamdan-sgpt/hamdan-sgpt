## 💫 About Me
Saya adalah seorang developer yang berfokus pada pengembangan **Minecraft Plugins** dan integrasi sistem menggunakan **Java** & **Python**. Selalu tertarik untuk merekayasa ulang mekanik game favorit ke dalam Minecraft secara mendalam dan performan!

* 🔭 Sedang mengerjakan: **[Exit 8 - Fresh Station](https://github.com/hamdan-sgpt/exit8_aseli_rill)** - Rekreasi stasiun Exit 8 di Minecraft.
* ☕ Spesialisasi: Java (Paper/Spigot API), Python (Automation & Scripting).
* ⚡ Hobi: Menjelajahi mekanika anomali game, mengoptimalkan resource pack, dan server deployment.
