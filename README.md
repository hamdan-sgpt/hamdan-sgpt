### 🕹️ Highlighted Game Builds

#### 🎲 [DONT-LIE-MOD](https://github.com/hamdan-sgpt/DONT-LIE-MOD)
> *Going Seventeen "Don't Lie" Minecraft Forge 1.20.1 Mod*
- **Architecture:** Mafia & Citizen role distribution, custom item models, and freeze timers.
- **Features:** Money Pouch hiding/re-hiding, automated parkour minigame, wealth leaderboard, and AAA Admin Control Panel.
- **Audio:** Native integration with Simple Voice Chat for proximity communication and night silence.
- `Java 21` `Forge 47.3.0` `Simple Voice Chat` `Packet Networking`

#### 👁️ [A-Elestial](https://github.com/hamdan-sgpt/A-Elestial)
> *Psychological Jumpscare Horror Mod (Forge 1.20.1)*
- **Atmosphere:** Obsidian Gothic GUI aesthetic, tension-building pacing, and 3D player skin heads.
- **Interactivity:** Real-time jumpscare events synced across clients with full proximity voice chat support.
- `Forge 1.20.1` `Gothic UI` `Horror Mechanics`

#### 🎵 [spoticraft-player](https://github.com/hamdan-sgpt/spoticraft-player)
> *In-Game Web Audio Companion Player*
- **Streaming:** Synchronized audio playback for the Minecraft 1.21 SpotiCraft plugin via YouTube audio API.
- **Client:** Responsive web player interface with dark mode and real-time playback controls.
- `HTML5 WebAudio` `JavaScript ES6+` `Plugin Companion` · [**Live Web Player ↗**](https://hamdan-sgpt.github.io/spoticraft-player/)

#### 🚪 [exit8-minecraft-plugin](https://github.com/hamdan-sgpt/exit8-minecraft-plugin)
> *The Exit 8 (8番出口) Horror Loop Plugin (Paper/Spigot 1.20+)*
- **Mechanics:** Endless repeating underground subway corridor with randomized anomaly generation.
- **Objective:** Spot anomalies and turn back, or continue forward to reach Exit 8.
- `Java` `Paper 1.20+` `Procedural Anomalies`

#### 🩸 [dead-by-daylight-mod](https://github.com/hamdan-sgpt/dead-by-daylight-mod)
> *Asymmetric Survival Horror Gameplay in Minecraft*
- **Mechanics:** 1 Killer vs 4 Survivors, generator repair mini-challenges, terror radius soundscape, and exit gate power-ups.
- `Java` `Forge Mod` `Asymmetric PvP`

#### 🪪 [RPGIdentityCard](https://github.com/hamdan-sgpt/RPGIdentityCard)
> *Dynamic In-Game Indonesian KTP Renderer*
- **Visuals:** Real-time 2D map renderer creating Indonesian KTP ID cards with player face skins and server citizenship info.
- `Paper/Spigot 1.20.1` `Map Canvas API` `RPG Identity`
